TripRoute - Quick Commands Reference
=====================================

START BACKEND:
--------------
cd backend
python server.py

OPEN FRONTEND (choose one):
----------------------------
# Windows:
start frontend\demo.html

# Mac:
open frontend/demo.html

# Linux:
xdg-open frontend/demo.html

# Or use local server:
cd frontend
python -m http.server 3000
# Then open: http://localhost:3000/demo.html

TEST BACKEND:
-------------
python test_backend.py

STOP BACKEND:
-------------
# In the backend terminal, press:
Ctrl + C

CHECK API KEYS:
---------------
# Backend:
cat backend/api.env

# Frontend:
cat frontend/config.js

VIEW LOGS:
----------
# Backend logs appear in terminal where you ran python server.py
# Frontend logs: Open browser, press F12, go to Console tab

HEALTH CHECK:
-------------
# Visit in browser:
http://localhost:8000/health

# Or use curl:
curl http://localhost:8000/health

API DOCUMENTATION:
------------------
# Visit in browser while backend is running:
http://localhost:8000/docs

COMMON ISSUES:
--------------
"Cannot connect to server"
→ Start backend: cd backend && python server.py

"Gray map"
→ Check frontend/config.js has your Google Maps key

"Port already in use"
→ Edit backend/server.py line 389, change port

COMPLETE FLOW:
--------------
1. cd backend && python server.py
2. Open frontend/demo.html in browser
3. Type: "I want to visit dessert shops in Toronto"
4. Wait for recommendations
5. Click "⚡ Quick Optimize"
6. See route on map!
