# 🌍 Travel Assistant Dashboard

A modern, responsive dashboard built with **React**, **Vite**, and **Tailwind CSS** for tracking your travels, managing destinations, and organizing your wishlist.

This dashboard provides a clean and interactive UI to view your active travel status, monitor trip statistics, and save future places you'd love to visit.

---

## ✨ Wishlist Example

Japan  
Shibuya Crossing  
Osaka Castle  

Australia  
Sydney Opera House  

You can:
- Add a country  
- Add a place  
- Automatically group multiple places under the same country  

---

## 🎨 Tech Stack

- **React (Vite)** — Fast frontend development  
- **Tailwind CSS** — Utility-first styling  
- **React Router DOM** — Page navigation  
- **JavaScript (ES6+)**

Planned integrations:
- Google Maps API  
- AI-based travel recommendations  
- Backend storage (Supabase, Firebase, or Express.js)
