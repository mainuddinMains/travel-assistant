# 🗺️ AI Travel Dashboard

A modern dashboard interface for managing travel plans — including active trips, distance summaries, and place information.

## 🚀 Features
- Sidebar navigation (Dashboard, Itinerary, Explore, Guide, Friends)
- Active trip display with total distance & time
- Place cards showing travel time, distance, and direction button
- Built with **React + TailwindCSS + Vite**

## 🛠 Setup
```bash
npm install
npm run dev
